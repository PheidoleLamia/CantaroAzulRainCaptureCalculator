# Installation Guide

## Prerequisites

- Node.js 20.x or later
- Git

## Steps

1. **Clone the repository**

   ```bash
   git clone https://github.com/PheidoleLamia/CantaroAzulRainCaptureCalculator.git
   cd CantaroAzulRainCaptureCalculator
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Run the development server**

   ```bash
   npm run dev
   ```

   Open [http://localhost:3000](http://localhost:3000) in your browser.

## Building for distribution

```bash
npm run build
```

Produces an `out/` folder. Zip it and share — recipients open `out/index.html` directly in a browser.
